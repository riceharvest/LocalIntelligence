# Every Gradle dependency and plugin this repo is allowed to use.
#
# If a coordinate is not on this list, CI fails. That is the point: the rule in
# docs/architecture.md is "Do not add dependencies unless it is genuinely
# necessary", and prose does not stop a swarm from adding Room, Retrofit and
# OkHttp "temporarily".
#
# Adding a line here is the ONLY way to add a dependency, and adding a line is a
# visible diff in a PR. The justification column is mandatory and non-empty:
# a dependency nobody can justify is one nobody needs.
#
# HOW TO ADD ONE (deliberately two steps, so it cannot happen by accident):
#   1. append the coordinate + a real justification below
#   2. add the dependency to gradle/libs.versions.toml
#   Both must land in the same PR, so the reviewer sees the justification and
#   the dependency together.
#
# Format: <coordinate-or-plugin-id> <TAB or 2+ spaces> <justification>
# Checked by scripts/check-dependencies.sh
#
# --- libraries -------------------------------------------------------------
# Coroutines: the agent loop is suspend-based; AgentController returns a flow
# of steps. Already unavoidable on Android.
org.jetbrains.kotlinx:kotlinx-coroutines-core	agent loop is suspend/flow-based
org.jetbrains.kotlinx:kotlinx-coroutines-android	Android Main dispatcher for :android
org.jetbrains.kotlinx:kotlinx-coroutines-test	runTest() for deterministic :core tests
# Serialization: the action protocol is JSON by definition (docs/architecture §5),
# and tool arguments are JsonObject. Hand-rolling this would be worse.
org.jetbrains.kotlinx:kotlinx-serialization-json	the wire format IS json; args are JsonObject
