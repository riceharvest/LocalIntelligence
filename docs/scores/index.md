# Scores

Generated by `docs/scores/build_scores.py` from the result files in `docs/scores/results/`. Do not edit this page by hand. A value marked *not measured* is absent from its result file.

Every result is the real app on a phone, driven through `scripts/devicectl.sh`. There is no desktop runner. Only complete runs feed the app's Simple setup.

Verdicts: **pass** and **fail** are decided by the checks in `evals/tasks.jsonl`. **unverified** means a check could not be decided from what the run could observe, and it counts as not passed. **wrong language** is a reply in the wrong language when every other check passed; it is counted apart.
