# Scores

Generated by `docs/scores/build_scores.py` from the result files in `docs/scores/results/`. Do not edit this page by hand. A value marked *not measured* is absent from its result file.

Two runners appear in separate tables. **device-app** is the real app on a phone through `scripts/devicectl.sh`. **desktop-app-loop** is the app's loop on a desktop llama-server, through a harness; it is not a phone figure. Only device-app complete runs feed the app's Simple setup.

Verdicts: **pass** and **fail** are decided by the checks in `evals/tasks.jsonl`. **unverified** means a check could not be decided from what the run could observe, and it counts as not passed.
