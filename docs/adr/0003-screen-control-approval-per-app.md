# Screen control asks once per app per request, never unattended

Screen control (full build only, Technical mode, off until the user enables the Accessibility service) can tap and type in other apps. Asking before every tap would make it unusable, and asking never would let text on someone else's screen steer it. So approval is given once per app per run: the card names the app and the user's request, and it covers only that app until the run ends. A tap on a control labelled send, pay, buy, delete, install or confirm always asks again. Auto-accept never applies, unattended runs never get screen control, and a Stop overlay is shown the whole time. The app never acts on its own screens, system Settings, the package installer or permission dialogs, so it cannot approve itself or grant itself access. Screen text is untrusted text.
