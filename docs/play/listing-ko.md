**자세한 설명**

LocalIntelligence는 휴대폰에서 언어 모델을 직접 돌리는 Android용 AI 어시스턴트예요.

이미 가진 모델을 고르거나, 추천 모델을 내려받으세요. 간단 모드에서는 추천 모델만 보여 줘요. 기술 모드에서는 Hugging Face의 나머지 모델과, 원격 서비스에 쓸 내 키를 추가로 쓸 수 있어요.

물어보시면 할 수 있는 일:
- 대화에서 질문에 답하고, 여러 단계로 된 작업을 함께 해요.
- 알람과 타이머를 맞추고, 일정을 보거나 추가해요.
- 연락처를 찾고, 앱을 열고, 고르신 파일을 읽고, 배터리를 확인해요.
- 보는 것을 허용하신 알림을 읽고 답장해요.
- LocalIntelligence를 기본 디지털 어시스턴트 앱으로 설정하셨을 때만 문자를 읽고, 최근 통화를 보고, 문자를 보내요. 문자를 보내기 전에는 항상 먼저 물어봐요.
- 모델이 지원하면 대화에 말로 입력하거나, 사진을 보내거나, 음성 클립을 녹음해요.
- 설정에서 호출어를 켜면 핸즈프리로 어시스턴트를 열어요.

휴대폰 밖으로 나가는 정보는 직접 설정하기 전까지 꺼져 있고, 네트워크를 쓸 때마다 먼저 물어봐요. 해당되는 것은 웹 검색과 웹 페이지 읽기, 날씨, 위키백과와 장소 검색, 그리고 내 키를 입력하는 원격 모델 제공자예요. 개인정보 처리방침에 각 서비스와 받는 정보가 나와 있어요.

개인정보: 계정, 분석, 충돌 보고, 광고가 없어요. 대화와 어시스턴트가 기억하는 내용은 휴대폰에 남고, 이 앱은 Android 백업이 꺼져 있어요. 답변은 답변 화면에서 바로 개발자에게 신고할 수 있어요. 신고 이유를 고르고, 메모를 덧붙이거나, 답변 내용은 빼고 보낼 수 있어요.

개인정보 처리방침: https://riceharvest.github.io/LocalIntelligence/privacy.html
